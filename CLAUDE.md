# EditPad

Lightweight plain-text and code editor for iOS and iPadOS 17+, built with SwiftUI. Opens any text file from the Files app, highlights about 30 languages, and saves files back with their original encoding, BOM and line endings.

## Layout

- `EditPad/` — SwiftUI app target (folder-synchronized: new files are added to the target automatically)
  - `EditPadApp.swift` — `DocumentGroup` scene
  - `TextDocument.swift` — `FileDocument` adapter over `EditPadKit`
  - `CodeTextView.swift` — `UITextView` wrapper: input traits, background highlighting, auto-indent, `KeyboardBar`
  - `EditorView.swift` — toolbar, options menu, Share, Show in Files
  - `SupportedFileTypes.swift` — generated; do not edit
  - `StatusBar.swift`, `SettingsView.swift`, `EditorSettings.swift`, `SyntaxTheme.swift`
- `Config/Info.plist` — document types and imported type declarations, generated by `scripts/generate-file-types.py` (merged with Xcode's generated Info.plist keys)
- `Packages/EditPadKit/` — Foundation-only core: `TextCodec`, `LineEnding`, `TextEncoding`, `SingleByteCodec`, `TextStatistics`, `SyntaxLanguage`, `SyntaxGrammar`, `SyntaxHighlighter`, `Indentation`
- `.github/workflows/ci.yml` — Linux and macOS package tests, iOS Simulator build

## Commands

```sh
# Core tests (works on Linux and macOS)
swift test --package-path Packages/EditPadKit

# App build (macOS with Xcode 16+)
xcodebuild build -project EditPad.xcodeproj -scheme EditPad \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO

# Regenerate file-type declarations after editing its tables
python3 scripts/generate-file-types.py

# Agent config check
bash scripts/verify-agents.sh
```

Without a Mac, push a branch and read the iOS build result from GitHub Actions (`gh run list --repo tannerpresscorp/editpad`).

## Rules

- Keep the app lightweight: no third-party dependencies unless a human asks.
- All decoding, encoding, line-ending, tokenizing and indentation logic belongs in `EditPadKit`, never in views.
- The editor is a `UITextView` (`CodeTextView`), not SwiftUI `TextEditor`: `TextEditor` can't disable spell checking or color text. Spell check, autocorrect, smart punctuation and predictions stay off by default.
- Never hand-edit `CFBundleDocumentTypes`/`UTImportedTypeDeclarations` in `Config/Info.plist` or `EditPad/SupportedFileTypes.swift`; edit `scripts/generate-file-types.py` and rerun it.
- Highlighting must stay off the main thread and skip files over `EditorSettings.highlightingLimit`.
- Unedited files must save byte-for-byte identical. Add a case to `testRoundTripPreservesBytes` for any new encoding or line-ending path; never weaken it.
- Don't use `String.Encoding.windowsCP1252` or `.isoLatin1`: Linux Foundation decodes them differently. Use `SingleByteCodec`.
- Don't hand-edit file references in `EditPad.xcodeproj/project.pbxproj`; synchronized folders handle them.
- Don't change the bundle identifier, signing or team settings.
- Record architecture decisions in `DECISIONS.md`.
